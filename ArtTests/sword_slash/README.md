# 이펙트 테스트 (pixelfx 합성)

- 출처: https://github.com/patch-gg/pixelfx (MIT, 상업용 가능. gallery/fonts 폰트만 제외)
- 결정: 원소(불·얼음·번개·물 등) 이펙트는 게임에 없으므로 제외 (2026-11-04 런들님)
- 방법: render.mjs --sheet --fps 24 로 시트를 뽑고, 정수배(×2/×3)로 키워 레인저 UAL2 몸+sword 레이어 위에 겹침.
  이펙트 기준점 = 캐릭터 발 기준점. 이펙트 1번 프레임이 모션 타격 프레임(json hitFrame)에 오도록 맞춤.
- 강철색 팔레트: #22262e #3c434f #5d6676 #8892a2 #b9c2d0 #e3e9f0 #ffffff
- slash_compare.gif: 찌르기(A)+thrust, 내려베기(B)+sword-slash/double-slash, 회전베기(C)+spin-slash
- impact_compare.gif: 나무꾼 상대로 hit-spark, crit-hit, parry
- 아직 게임(Unity)에는 넣지 않음. 테스트 이미지만.

## 2차: 칼끝 궤적 슬래시 (trail_compare.gif, 2026-11-04)
- 무기 레이어에서 프레임마다 칼(손잡이~칼끝) 위치·각도를 뽑고, 휘두르는 구간 사이를 각도로 이어 칼날이 쓸고 간 면을 그림.
- 모션마다 한 번 정하는 값: 휘두름 시작·끝 프레임, 방향. A(sword_regular_a) 4~7 반시계(올려베기), B(sword_regular_b) 3~6 시계(내려베기).
- 칼이 화면 쪽을 향해 짧게 보이는 프레임(길이 40% 미만)은 읽을 수 없어 건너뜀.
- 색은 pixelfx 강철색, 꼬리 디더, 칼끝 흰 테두리, 가장 빠른 순간에 불꽃. 1배 해상도(캐릭터와 같은 픽셀 크기)로 그림.
- 타격(hit-spark ×1)은 json 타격 프레임 + 1에 맞춤.
- 아직 Unity에는 넣지 않음.

## 5차: 매끈한 곡선 (2026-11-04, 시험)
- 런들님: 칼을 그대로 따라가니 꺾이는 곳이 있음 → 부드러운 곡선으로.
- 원인: 프레임 사이를 직선으로 이어서 키 프레임마다 속도·반지름·손 위치가 갑자기 바뀜.
- 고친 방식(tools/trail3.py): 휘두름마다 중심 하나(손 위치 평균)를 고정, 각도는 단조 3차 곡선(PCHIP), 반지름은 2차식으로 맞춤.
  두께는 꼬리에서 머리카락처럼 시작해 머리 80% 지점이 가장 두껍고, 머리 끝은 둥글게 좁아짐.
- 비교: smooth_compare_single.gif (A, B, 회전, 대시), smooth_compare_combo.gif (연속, 강공격). 왼쪽 "지금", 오른쪽 "매끈하게".

## 7차: 타원 (2026-11-04, 시험)
- 런들님: 매끈 버전이 원형이라 날카로운 느낌이 덜함 → 타원에 가깝게.
- tools/trail4.py: 원을 휘두름 가운데 방향으로 a배, 그 옆 방향으로 b배 늘린 타원. 약하게 (0.85, 1.2), 강하게 (0.7, 1.35).
  타원으로 바꾸면 칼끝에서 벗어나서, 읽은 프레임의 실제 칼끝과의 차이를 부드러운 곡선으로 더해 칼끝을 지나가게 함.
  머리 끝은 둥글게가 아니라 뾰족하게 좁아짐.
- ellipse_compare_single.gif (A, 회전 15-17, 대시), ellipse_compare_combo.gif. 열: 그대로 / 매끈 원형 / 타원 약하게 / 타원 강하게.
