# 캐릭터 굽기 툴 (테스트 버전)

3D 캐릭터에 모션을 입혀서, 전투용 도트 스프라이트 시트로 굽는 유니티 툴.
전투는 횡스크롤 한 방향(오른쪽 보기)으로 굽고, 왼쪽은 게임에서 좌우 반전해서 쓴다.

## 쓰는 법

1. 유니티를 열면 `Assets/Art3D` 안의 3D 파일을 자동으로 가져온다. 처음엔 몇 분 걸린다.
2. 메뉴 `CardGame > 캐릭터 굽기 > 테스트 설정 만들기`
   - `Assets/Art3D/BakeSetups/` 에 설정 두 개가 생기고 굽기 창이 열린다.
   - `test_sword_shield`: 레인저 옷 + 한손검 + 임시 원판 방패 + 검방패 모션 13개
   - `test_axe`: 농부 옷 + 짧은 머리 + 수염 + 도끼 + 도끼 모션 10개
3. 창 위쪽 미리보기에서 모션과 프레임을 골라 확인한다. `재생` 으로 움직임도 볼 수 있다.
4. `체크된 모션 전부 굽기` 를 누르면 `Assets/Art/characters/<설정이름>/` 에 저장된다.
   - `모션이름.png`: 가로 한 줄 스프라이트 시트 (프레임마다 잘려 있음)
   - `모션이름.json`: fps, 프레임 수, 발 위치, 타격 프레임 번호

## 기본 값

| 항목 | 값 | 뜻 |
|---|---|---|
| 프레임 크기 | 128 x 96 | 발은 왼쪽에서 48px, 아래에서 6px. 크게 움직이는 모션은 그 모션만 자동으로 넓힘 (json에 실제 크기 기록) |
| 1미터 | 36px | 키 1.8m 캐릭터가 약 65px |
| 카메라 | 완전한 옆모습 (돌림 0도, 내려보기 0도) | 두 발이 같은 바닥선, 무기 든 오른손이 카메라 쪽 |
| fps | 12 | 1초에 12장 |
| 명암 | 3단계 | 밝음 / 중간 / 그림자 |
| 윤곽선 | 1px | 진한 보라 갈색 |
| 팔레트 | 없음 | 팔레트 PNG를 넣으면 그 색으로만 굽는다 |

## 자주 만질 설정

설정 항목 이름은 영어로 보이고, 마우스를 올리면 한국어 설명이 나온다.

- **무기가 이상하게 쥐어지면**: `Weapon > Auto Grip` 을 켠 채 `Extra Rotation` 으로 돌려 본다. 칼날이 거꾸로면 `Flip Grip` 체크.
- **옷 밖으로 맨살이 비치면**: `Hide Body Under Clothes` 를 켠다 (기본 켜짐, 옷을 입히면 기본 몸은 머리만 남긴다). 목 쪽이 비면 `Keep Body Bones` 에 `spine_03` 을 더한다.
- **발이 하이힐처럼 보이면**: `Flatten Feet` 를 켠다 (기본 켜짐). 바닥에 닿은 발은 발끝이 앞을 보게 돌리고 발바닥을 평평하게 맞춘다. 원래 모션 느낌이 더 좋으면 `Flatten Feet Amount` 를 낮춘다.
- **몸이 비틀려 보이거나 모션 도중 뒤를 보면**: `Straighten Hips` 를 켠다 (기본 켜짐). 골반의 좌우 돌아감과 옆 기울기를 펴서 늘 오른쪽을 곧게 본다. 앞뒤 숙임은 그대로. 세기는 `Straighten Hips Amount`.
- **발이나 몸이 바닥 아래로 파고들면**: `Keep Above Ground` (기본 켜짐). 몸 메시의 가장 낮은 점이 바닥 아래면 그만큼 올려서 굽는다 (무기, 방패는 제외).
- **키 조절**: `Height Scale` (0.9 작게, 1.15 크게).
- **그림이 위아래로 뒤집혀 나오면**: `Flip Y` 체크. (보통은 자동으로 맞춘다)
- **칼끝이 프레임 밖으로 나가면**: `Frame Width` 를 160으로 늘리거나 `Pixels Per Meter` 를 32로 줄인다.

## 타격 프레임

공격 모션은 무기 끝이 화면에서 가장 빠르게 움직이는 순간 직전 프레임을 타격 프레임으로 잡는다.
눈으로 봐서 다르면 모션 목록의 `Hit Frame Override` 에 번호를 직접 넣는다 (-1 이면 자동).
미리보기 위에 빨간 줄이 보이면 그 프레임이다. 게임에서는 이 프레임에 멈춤(히트스톱), 슬로우, 이펙트를 건다.

## 파일 구성

```
Assets/Art3D/
  Characters/Base      기본 몸 (휴머노이드)
  Characters/Outfits   옷 (뼈 이름으로 몸에 붙음)
  Characters/Hair      머리카락, 수염, 눈썹
  Animations/UAL       Quaternius 모션 (UAL1)
  Animations/Mixamo    Mixamo 모션 (SwordShield, Axe, Singles)
  Weapons              무기
  Shaders              굽기 전용 셰이더
  BakeSetups           굽기 설정
Assets/Scripts/Editor/Character/   굽기 툴 코드
```

- `Art3D` 는 약 140MB. 깃에 올리기 무거우면 나중에 Git LFS 를 쓰거나 이 폴더만 따로 보관한다.
- 맵 타일 굽기와 팔레트 색 계산 방식이 같다 (`PixelArtUtil.Nearest`).
