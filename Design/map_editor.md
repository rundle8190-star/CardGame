# 맵 편집기 사용법

Unity 메뉴 **CardGame > 맵 편집기** 로 연다. 맵은 `Assets/Data/Maps/<맵 id>.json` 으로 저장된다.

## 조작
| 할 일 | 방법 |
|---|---|
| 지형 칠하기 | 도구 "지형"(1) → 지형 고르기 → 왼쪽 클릭·드래그. 붓 크기로 넓게 칠함 |
| 노드 찍기 | 도구 "노드"(2) → 종류 고르기 → 칸 클릭. 있던 노드는 종류만 바뀜 |
| 노드 고르기·옮기기 | 도구 "선택"(3) → 클릭해서 고르고 끌어서 옮김. 왼쪽 "고른 노드"에서 이름·전투 칸 수·난이도·적 계열·메모 수정 |
| 노드 지우기 | 오른쪽 클릭(어느 도구든), 도구 "지우기"(4), 또는 Delete 키. 그 노드에 붙은 길도 같이 지워짐 |
| 길 잇기 | 도구 "길"(5) → 노드를 차례로 클릭하면 앞 노드와 이어짐. 이어진 두 노드를 다시 클릭하면 끊김. 선을 클릭하면 그 길만 지움. 빈 칸 클릭이나 Esc로 잇기 멈춤 |
| 길 자동 연결 | 도구 "길"(5) → "가까운 노드 자동 연결". 걸어서 가까운 노드끼리 모두 이어지게 하고 이웃을 하나씩 더 잇는다(엇갈리는 길은 안 만듦). 이미 있는 길은 그대로 |
| 화면 옮기기 / 확대 | 가운데 버튼 드래그 / Ctrl + 휠 |
| 되돌리기 / 다시 / 저장 | Ctrl+Z / Ctrl+Y / Ctrl+S |

## 규칙
- 이동은 상하좌우 한 칸씩. 산·물·맵 밖은 지나갈 수 없다.
- 시작 지점은 맵에 1개만 둔다(새로 찍으면 이전 것은 지워짐).
- 전투 칸 수는 노드에서 따로 정하지 않으면 지형 기본값(들판 9, 길·숲·언덕 7, 깊은 숲·늪·폐허·다리 5).
- 적 계열을 노드에서 하나도 고르지 않으면 맵 기본 적 계열을 쓴다.
- 왼쪽 아래 "검사"가 시작 지점 없음, 막힌 칸 위 노드, 시작에서 못 가는 노드, 시작에서 길로 이어지지 않은 노드, 탈출 후보 부족 등을 알려 준다. "시작에서 걸음 수"를 켜면 칸마다 걸음 수가 보인다.

## 종류 추가·변경
지형·노드 종류·적 계열 목록은 `Assets/Scripts/Core/Map/MapCatalog.cs` 한 파일에 있다. 지형 문자는 저장된 맵에 그대로 쓰이므로 이미 쓰는 문자는 바꾸지 않는다.

## 예시
`Assets/Data/Maps/plains.json` — 평원 36×24, 노드 45개(맵 설계 초안 3장 개수 기준). 강 하나와 다리, 북동쪽 산지, 남쪽 숲, 도적 요새(큰 던전), 숲·산지로 가는 이동 노드.

## 랜덤 칸

노드 도구에서 **랜덤 칸(랜)**을 찍어 두면, 탐험을 시작할 때마다 생성기(`Core/Map/RandomNodeGenerator.cs`)가 실제 노드로 바꿔요. 직접 찍은 노드는 그대로 두고 랜덤 칸만 바뀌어요.

- **후보 적는 법:** `종류:가중치` 또는 `종류:가중치:최대 개수`를 쉼표로 이어요. 예: `battle:40, elite:8:3, farm:15`
- **우선순위:** 칸의 후보 → 맵의 '랜덤 칸 기본 후보' → 기본값 순서로 써요.
- **기본값:** `battle:40, elite:8:3, farm:15, event:20, totem:6:3, ruin_village:5:2, merchant_camp:4:1`
- **최대 개수:** 직접 찍은 같은 종류 노드까지 세요. 예를 들어 상인을 1곳 찍어 두었고 `merchant_camp:4:1`이면 랜덤으로는 상인이 나오지 않아요.
- **엘리트:** 시작 지점에서 6걸음 안쪽에는 나오지 않아요.
- **흩어 두기:** 같은 종류가 2칸 안에 이미 있으면 그 종류가 나올 확률이 1/4로 줄어요.
- **남는 경우:** 뽑을 후보가 없으면 전투가 돼요.
- **랜덤 칸의 전투 설정:** 전투 칸 수, 난이도, 적 계열을 적어 두면 전투나 엘리트가 나왔을 때 그 설정을 써요.

웹 편집기의 '랜덤 굴려 보기'는 유니티와 같은 계산을 써요. 그래서 같은 시드를 넣으면 결과도 같아요. 숫자(6걸음, 2칸)는 `RandomNodeGenerator`의 `EliteMinSteps`, `SpreadRadius`에서 바꿀 수 있고, 바꾸면 웹 편집기의 `ELITE_MIN_STEPS`, `SPREAD_RADIUS`도 같이 맞춰야 해요.

## 맵 플레이 (탐험 시험)
편집기 위쪽 **▶ 플레이**를 누르면 맵을 저장하고 `Assets/Scenes/MapPlay.unity` 를 만들어(없을 때) 바로 플레이한다. 메뉴 **CardGame > 맵 플레이 씬 만들기** 로 씬만 만들 수도 있다.

- 화면은 쿼터뷰(2:1 마름모)다. 편집기는 그리기 편하게 위에서 본 격자 그대로 둔다.
- 이동은 보드게임 방식이다. 길로 이어진 이웃 노드로 한 번에 하나씩 옮겨 간다. 이웃 노드를 클릭하거나, W·A·S·D(방향키)로 화면에서 그쪽에 있는 이웃 노드로 간다. 지금 노드에서 나가는 길은 노란색이고, 갈 수 있는 노드는 조금 크게 보인다. 휠로 확대·축소, B 키로 배낭.
- 맵에 길이 하나도 없으면 플레이할 때 자동 연결로 이어서 시작한다.
- 시야: 길로 1번 너머 노드까지 종류가 보이고, 그다음 한 겹은 "?"로 보인다(config 의 visionHops). 보이는 노드 둘레 지형도 밝아진다(visionRadius). 한 번 본 곳은 회색으로 지도에 남는다. 지도 기억은 탐험이 끝나도 남고, 화면의 "지도 기억 지우기"로 지운다.
- 전투 노드에 들어가면 전투 화면 대신 "이겼다 / 졌다" 버튼이 나온다(임시). 이기면 체력이 깎이고 재화와 적 무기(무게 5)를 얻는다.
- 3번 이동할 때마다 가장 오래전에 이긴 전투 노드 1곳에 적이 다시 생긴다(config 의 respawnEvery).
- 난이도 자동 계산의 "깊이"는 시작에서 길로 몇 번 이동하는지로 센다.
- 탈출 후보 중 2곳만 열린다(탐험마다 섞음). 열린 곳에서 탈출하면 끝.
- 무게가 최대치를 넘으면 정보창에 막히는 전투 슬롯 수가 나오고, 125%를 넘으면 움직일 수 없다.
- 임시 수치(체력 50, 무게 100, 피해·보상 등)는 씬의 Map Player 오브젝트 Inspector 의 config 에서 바꿀 수 있다.
- 아직 없는 것: 실제 전투, 던전 안쪽, 다른 맵 이동, 상점, 거점·창고, 약탈자.

## 쿼터뷰 타일 그림 규격
| 항목 | 값 |
|---|---|
| 한 칸 크기 | 가로 64px, 바닥 마름모 세로 32px (2:1). 위로 솟는 부분(나무, 바위, 건물)은 그 위로 더 그린다 |
| 그림 크기 | 64 × (32 + 솟는 높이). 굽기 툴 기본값은 64 × 96 |
| 기준점 | 바닥 마름모의 아래 꼭짓점 = 그림 맨 아래 가운데 |
| 카메라 (3D로 구울 때) | 직교, 아래로 30도, 옆으로 45도. 캐릭터도 같은 각도·같은 픽셀 크기로 구워야 어울린다 |
| 3D 모델 | 바닥 1×1 칸, 바닥 가운데가 원점, 바닥 높이 y = 0 |
| 파일 위치·이름 | 지형: `Assets/Art/tiles/<지형 id>.png`, 변형은 `<지형 id>_2.png` … (칸마다 정해진 하나가 고정으로 나옴). 노드: `Assets/Art/map_nodes/<노드 종류 id>.png` |
| 지형 id | field 들판, road 길, forest 숲, deep 깊은 숲, hill 언덕, swamp 늪, snow 눈밭, ruin 폐허, bridge 다리, mountain 산, water 물, void 맵 밖 |
| 노드 id | start, battle, elite, farm, event, totem, ruin_village, merchant_camp, small_dungeon, big_dungeon, exit, map_gate |

- **쿼터뷰 타일 굽기** (메뉴 CardGame > 쿼터뷰 타일 굽기): 3D 모델을 넣고 "굽기"를 누르면 위 규격의 PNG 가 저장된다. 팔레트 그림을 넣으면 모든 픽셀을 팔레트 색으로 바꾼다.
- 3D 모델에 빛이 안 들어가 까맣게 나오면: 이 프로젝트 기본 렌더러가 2D 렌더러라서다. `Settings/UniversalRP` 의 Renderer List 에 Universal Renderer 를 하나 더하고 그 번호를 굽기 툴 "렌더러 번호"에 넣는다.
- 손으로 그리거나 산 그림도 같은 이름·위치에 넣으면 된다. 플레이 버튼을 누를 때 가져오기 설정(점 필터, 압축 없음, 기준점)이 자동으로 맞춰지고 화면에 연결된다. 메뉴 CardGame > 맵 그림 가져오기 설정 맞추기 로 따로 맞출 수도 있다.
- 그림이 없는 지형·노드는 색 마름모로 나온다.
- 아직 남은 것: 지형 경계 타일(자동 연결), 안 보이는 곳을 팔레트 색으로 어둡게 하기(지금은 색을 곱해서 어둡게 함), 픽셀 떨림 방지 카메라.
