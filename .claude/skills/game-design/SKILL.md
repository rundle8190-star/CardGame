# 게임 기획서 작성

코드를 쓰기 전에 아래 템플릿으로 `docs/design/<게임-id>.md`를 만든다. 게임-id는 영문 소문자와 하이픈만 쓴다 (예: `card-duel`).

사용자가 정하지 않은 항목은 가장 단순한 선택으로 채우고 `(가정)` 표시를 붙인 뒤, 답변에서 그 가정들을 한 번에 알려준다.

## 템플릿

```markdown
# <게임 이름> (`<게임-id>`)

## 한 줄 소개
## 핵심 루프
플레이어가 반복하는 행동 3단계 이내.
## 규칙
- 승리 조건:
- 패배 조건:
- 점수:
## 조작
| 입력 | PC | 모바일 |
## 화면
시작 화면 / 플레이 화면 / 결과 화면에 무엇이 보이는지.
## 멀티플레이 여부
싱글 / 같은 화면 2인 / 온라인 (온라인이면 서버 방식 명시)
## 1차 완성 범위 (MVP)
- [ ] ...
## 나중에 할 것
```

## 완료 기준
- MVP 체크리스트가 5개 이하로 구체적이다.
- 규칙만 읽고 다른 사람이 게임을 설명할 수 있다.
